Bark's first signed macOS release for Apple Silicon.

- Native sidebar with spaces, profiles, pinned tabs, and Chrome extensions.
- Signed with Apple Developer ID and notarized by Apple.
- Signed automatic update checks through Sparkle and GitHub Releases.

Bark is experimental. This is an early release of the Chromium source migration;
complete interface parity and migration from retired preview builds remain in progress.
Requires an Apple Silicon Mac and macOS 13 or later. Unzip Bark.app and move it to
Applications before launching. Update settings are in the Bark application menu.
