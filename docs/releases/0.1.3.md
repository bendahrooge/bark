Chromium 158, browser data import, and sidebar improvements.

- Updated the browser engine to Chromium 158.0.8127.37.
- Preview and select profiles, spaces, pinned tabs, bookmarks, and history to import into Bark. Imported profiles remain separate, and retrying an import avoids duplicates. Extensions are listed with links to reinstall them.
- Reduced redundant sidebar updates and favicon loading.
- Added haptic feedback when dragging tabs between insertion positions or into split view.
- Quit with Command-Q immediately, without holding the keys to confirm.

Signed with Apple Developer ID and notarized by Apple. Requires an Apple Silicon
Mac and macOS 13 or later. Move Bark.app to Applications before launching.
Existing installations can update through **Bark → Check for Updates…**.
