A faster Bark, split view, and new keyboard shortcuts.

- Bark is now compiled like other shipping Chromium browsers (profile-guided and link-time optimisation, no debug assertions), so pages, scrolling and the interface respond noticeably faster. The download is also much smaller.
- Split view: drag a tab from the sidebar onto the left or right half of the page to open it beside the current tab.
- Bark now has shortcuts for switching spaces and toggling the sidebar. Find the full list under **Help → Keyboard Shortcuts**.
- Settings has a direct link to import data from another browser.

Signed with Apple Developer ID and notarized by Apple. Requires an Apple Silicon
Mac and macOS 13 or later. Move Bark.app to Applications before launching.
Existing installations can update through **Bark → Check for Updates…**.
